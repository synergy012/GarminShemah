# Font provenance

The two original Noto fonts were supplied by the environment's Debian
`fonts-noto-core` package. See `DEBIAN-COPYRIGHT` for the upstream attribution and
licensing record and `OFL.txt` for the font license. No package-manager scripts or
Debian packaging code have been incorporated.

- `NotoSerifHebrew-Regular.ttf`: Hebrew letters, vowels and Hebrew punctuation.
- `NotoSerif-Regular.ttf`: matching serif punctuation and Latin characters.
- `SiddurSerif-Regular.ttf`: renamed derivative generated by
  `python -m tools.prepare_font` using fonttools 4.61.1. Original shaping tables
  are merged. The derivative remains licensed under OFL 1.1.

`SHA256SUMS` records the committed binaries. Setup rebuilds the derivative to a
temporary file and checks it byte-for-byte without editing the tracked font.
The application bundles derived raster documents rather than a runtime font.

Upstream project: <https://github.com/notofonts/noto-fonts>.
